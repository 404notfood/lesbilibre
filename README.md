# lesbi

Stack Podman generated by **Container Stack Generator**.

**Runtime:** Podman

**Preset:** Laravel

## Services

- **Nginx** (web server)
- **PHP-FPM 8.4**
- **Node.js 24**
- **MySQL 8.4**
- **Redis 7**
- **phpMyAdmin** (:8082)
- **Mailpit** (SMTP :1025, UI :8025)

## Environnement de développement

**Linux standalone**

Le SSL est géré directement par les containers Podman.

### Démarrage

```bash
chmod +x start-containers.sh
./start-containers.sh
```

### Arrêt

```bash
chmod +x stop-containers.sh
./stop-containers.sh
```

### Accès

- Application: https://lesbi.test
- SSL via Let's Encrypt

## Quick start (manuel)

```bash
 up -d
 logs -f
```

## Laravel setup

```bash
# Create project in src/
 exec php composer create-project laravel/laravel . "12.*"
# Copy the generated .env
cp .env.example src/.env  # then merge with generated values
 exec php php artisan key:generate
 exec php php artisan migrate
```

## SSL (Let's Encrypt)

```bash
 run --rm certbot certonly --webroot --webroot-path /var/www/certbot -d lesbi.test
 restart nginx
```
